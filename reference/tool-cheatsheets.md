# NVIDIA Tool Command Cheat Sheets

This reference provides quick command invocations for the key NVIDIA tools used throughout the labs. Each section corresponds to one tool, listing the 3–5 most commonly used commands with brief descriptions. Detailed explanations of what each tool measures and how to interpret its output are in the `docs/toolkit/` reference docs.

These cheat sheets will be populated as the tools are introduced and used in the labs.

---

## nvidia-smi

**Purpose:** GPU monitoring and inventory — query GPU properties, utilization, temperature, clocks, topology, and running processes.

Commands to be filled as used in labs.

---

## DCGM (dcgmi)

**Purpose:** Datacenter GPU management and diagnostics — health checks, stress tests, telemetry collection, and field value queries.

Commands to be filled as used in labs.

---

## Nsight Systems (nsys)

**Purpose:** System-wide profiling and tracing — captures GPU kernel execution, CPU activity, CUDA API calls, and NVTX markers across processes and devices.

Commands to be filled as used in labs.

---

## Nsight Compute (ncu)

**Purpose:** Kernel-level profiling and optimization — detailed analysis of individual CUDA kernels, memory throughput, compute utilization, and roofline modeling.

Commands to be filled as used in labs.

---

## nvbandwidth

**Purpose:** GPU memory and interconnect bandwidth benchmarking — measures HBM bandwidth, P2P GPU-to-GPU bandwidth over NVLink or PCIe, and host-device transfer rates.

Commands to be filled as used in labs.

---

## nccl-tests

**Purpose:** NCCL collective communication benchmarking — measures bandwidth and latency of all-reduce, all-gather, reduce-scatter, and broadcast across GPUs and nodes.

Commands to be filled as used in labs.

---

## perftest (ib_write_bw, ib_read_bw)

**Purpose:** RDMA fabric bandwidth and latency testing — measures raw RDMA or RoCE performance between nodes, independent of GPU or NCCL.

Commands to be filled as used in labs.

---

## ethtool

**Purpose:** Ethernet NIC statistics and configuration — inspect link speed, MTU, offload settings, RoCE counters, and packet drop statistics.

Commands to be filled as used in labs.

---

## kubectl (GPU-specific)

**Purpose:** Kubernetes cluster inspection and workload management — query GPU device plugin status, schedule GPU workloads, and inspect resource allocation.

Commands to be filled as used in labs.
